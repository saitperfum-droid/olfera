# OLFÉRA парфум

Офіційний сайт магазину преміум-парфумерії **OLFÉRA парфум** у Бердичеві.

## Як відкрити сайт

1. Зайди в репозиторій → **Settings** → **Pages**
2. У розділі **Source** обери **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Натисни **Save**

Через 1–2 хвилини сайт буде доступний за адресою:

**https://saitperfum-droid.github.io/olfera**
